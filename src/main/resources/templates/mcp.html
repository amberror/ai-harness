MCP servers

The harness runs the MCP client itself rather than letting LM Studio do it. That is the same decision as owning the agentic loop, for the same reason: a call made by someone else can be watched but not governed. Tools from a server are imported into the registry, so an MCP tool is validated, versioned, journalled and editable exactly like a built-in one.

Launching a stdio server runs a program. A server configuration is editable at runtime, so without a list this page would also be a way to execute arbitrary commands. The executable must be named in harness.mcp.stdio.allowed-commands. Nothing is currently allowed, so no stdio server can start. Currently allowed: []. Arguments are deliberately not restricted — an allowed interpreter will run whatever script it is handed, so checking them would be false assurance.
