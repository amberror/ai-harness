Evaluation

The unit of measurement here is a batch, not a run. For a 4B model a single passing run is an anecdote — even at temperature zero the same prompt does not always produce the same behaviour. Running a scenario N times and reporting the pass rate is the smallest claim worth making, and comparing two batches that differ in exactly one thing is the only way to attribute a change to anything.
