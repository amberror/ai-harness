Why tool-use capability is called out. The harness drives the agentic loop itself over the OpenAI-compatible endpoint, because LM Studio's native /api/v1/chat accepts neither custom tools nor assistant messages. Driving a model that was not trained for tool calling is the most common cause of a model that simply ignores the tools it was given.
